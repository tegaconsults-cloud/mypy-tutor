🎙 Sir. Tega Voice — Integration Guide

How to add TTS (text-to-speech) and STT (speech-to-text) to the MyPy Tutor Vercel frontend using the voice.js module served from the backend.

What's included

  • 🔊 Text-to-Speech (TTS) — Sir. Tega reads AI responses aloud using the browser Web Speech API. Zero external dependencies, zero cost.
  • 🎤 Speech-to-Text (STT) — user speaks questions into the chat input. Defaults to Nigerian English (en-NG).
  • 🎙 Voice settings panel — floating button opens a panel: voice picker, speed, pitch, volume, auto-speak toggle.
  • 💾 Persistent prefs — voice preferences saved to localStorage, survive page reloads.
  • 📱 iOS-safe chunked TTS — long responses split into sentence chunks to avoid the iOS 15 speech cut-off bug.

Backend endpoints

POST /tts/prepare — strips markdown, returns clean speakable text
GET /tts/voices — returns priority-ordered voice name list for the picker

Both are served from the same origin as the API. No auth required.

/tts/prepare request

POST /tts/prepare
Content-Type: application/json

{ "text": "Your **markdown** AI response here..." }

// Response:
{ "text": "Your markdown AI response here...", "char_count": 43, "truncated": false }

Step 1 — Load the script

Add this once in your HTML, just before </body>:

<script src="https://mypytutor.onrender.com/static/voice.js"></script>

Or, if the frontend is served from the same origin as the API (Vercel + CORS configured):

<script src="/static/voice.js"></script>

Step 2 — Initialise

Call SirTegaVoice.init() once when the page loads:

SirTegaVoice.init({
  // Required
  apiBase:       'https://mypytutor.onrender.com',   // or window.location.origin

  // Optional — defaults shown
  inputSelector: '#chat-input',    // CSS selector for the chat message input field
  micBtnId:      'voice-mic-btn',  // id for mic button (auto-created next to input)
  speakBtnClass: 'sir-tega-speak-btn', // class added to every 🔊 button
  autoSpeak:     false,            // auto-read every new AI response
});
⚡ inputSelector must point to your chat text input. The mic button is inserted immediately after it in the DOM. If your input doesn't exist yet (SPA routing), call SirTegaVoice.init() after the chat panel is rendered.

Step 3 — Wire to your chat messages

Every time a new AI response arrives, call onNewResponse():

// After you render an AI message bubble into the DOM:
function handleAIResponse(responseText) {
  // 1. Render the bubble (your existing code)
  const bubble = document.createElement('div');
  bubble.className = 'message assistant';
  bubble.innerHTML = marked.parse(responseText);  // or however you render markdown
  chatContainer.appendChild(bubble);

  // 2. Wire voice — attaches 🔊 button + auto-speaks if enabled
  SirTegaVoice.onNewResponse(bubble, responseText);
}

That's it. The 🔊 Listen button appears on the bubble automatically. Users can also open Voice Settings via the floating 🎙 button (bottom-right corner).

Step 4 — Auto-submit on voice input (optional)

If you want voice input to submit the form automatically after the user stops speaking:

// In your SpeechRecognition onend handler, or listen for the input event:
document.getElementById('chat-input').addEventListener('input', function (e) {
  // Only auto-submit if the value was set by voice (not manual typing)
  if (SirTegaVoice.isMicActive()) return; // still speaking — wait for onend
  // You can check a flag you set in your own mic flow, or just let the user submit
});

// Alternatively, pass a submit callback to the voice module's onend:
// Override the mic button's click to show a "Send?" confirmation toast
document.getElementById('voice-mic-btn')?.addEventListener('click', () => {
  if (!SirTegaVoice.isMicActive()) return;
  // recognition is running — clicking again stops it; onend will fire
});

Minimal full-page example

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8"/>
  <title>MyPy Tutor Chat</title>
</head>
<body>
  <div id="chat-messages"></div>
  <div id="chat-bar">
    <input id="chat-input" type="text" placeholder="Ask Sir. Tega…"/>
    <!-- mic button auto-inserted next to input by voice.js -->
    <button onclick="sendMessage()">Send</button>
  </div>

  <script src="https://mypytutor.onrender.com/static/voice.js"></script>
  <script>
    const API = 'https://mypytutor.onrender.com';
    const token = localStorage.getItem('mpt_token') || '';

    // ── Init voice ──────────────────────────────────────────────────────
    SirTegaVoice.init({
      apiBase:       API,
      inputSelector: '#chat-input',
      autoSpeak:     false,
    });

    // ── Send message ────────────────────────────────────────────────────
    async function sendMessage() {
      const input = document.getElementById('chat-input');
      const text  = input.value.trim();
      if (!text) return;
      input.value = '';

      // Stop any ongoing speech when user sends a new message
      SirTegaVoice.stop();

      // Append user bubble
      appendBubble(text, 'user');

      const res  = await fetch(API + '/chat', {
        method:  'POST',
        headers: { 'Content-Type': 'application/json',
                   'Authorization': 'Bearer ' + token },
        body: JSON.stringify({ message: text, learner_id: 'demo', level: 'beginner' }),
      });
      const data = await res.json();

      // Append AI bubble and wire voice
      const bubble = appendBubble(data.content || data.error, 'assistant');
      SirTegaVoice.onNewResponse(bubble, data.content || '');
    }

    function appendBubble(text, role) {
      const el = document.createElement('div');
      el.className = 'message ' + role;
      el.textContent = text;
      document.getElementById('chat-messages').appendChild(el);
      el.scrollIntoView({ behavior: 'smooth' });
      return el;
    }

    // Submit on Enter
    document.getElementById('chat-input').addEventListener('keydown', e => {
      if (e.key === 'Enter' && !e.shiftKey) { e.preventDefault(); sendMessage(); }
    });
  </script>
</body>
</html>

Full SirTegaVoice API

// Lifecycle
SirTegaVoice.init(options)              // initialise (call once)

// TTS
SirTegaVoice.speak(text)               // speak text (async, handles markdown strip)
SirTegaVoice.stop()                    // cancel speech immediately
SirTegaVoice.toggle(text)              // speak if silent, stop if speaking
SirTegaVoice.isSpeaking()             // → boolean

// STT
SirTegaVoice.toggleMic()              // start/stop microphone
SirTegaVoice.isMicActive()            // → boolean

// UI
SirTegaVoice.onNewResponse(el, text)  // attach 🔊 button + auto-speak
SirTegaVoice.attachSpeakButton(el, text) // attach 🔊 button only (no auto-speak)
SirTegaVoice.openSettings()           // open voice settings panel
SirTegaVoice.closeSettings()          // close voice settings panel
SirTegaVoice.toggleSettings()         // toggle settings panel
SirTegaVoice.isSupported()            // → boolean (false = no Web Speech API)

Browser support

  • ✓ Chrome / Edge / Brave — full TTS + STT
  • ✓ Safari 14.1+ (iOS + macOS) — TTS works; STT requires user gesture
  • ✓ Firefox 49+ — TTS works; STT not supported (mic button hidden automatically)
  • ✓ Android Chrome — full TTS + STT
  • ⚠ Firefox Android — TTS only, no STT

The module checks 'speechSynthesis' in window before any call. All voice UI is hidden automatically when not supported — your chat works fine without it.
