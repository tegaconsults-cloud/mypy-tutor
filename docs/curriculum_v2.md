## Pillar 3 — Machine Learning, Data Science and Advanced AI Engineering

### A. Machine Learning Foundations
- Introduction to Machine Learning
- AI vs ML vs Deep Learning
- Types of machine learning
- Mathematical foundations: linear algebra, probability, statistics, calculus, optimisation
- Data preparation and feature engineering
- Model training, testing and evaluation

### B. Supervised Learning
- Linear, multiple and polynomial regression
- Logistic regression
- Decision trees and random forests
- Support Vector Machines (SVM)
- K-Nearest Neighbours (KNN)
- Naive Bayes
- Gradient boosting: XGBoost, LightGBM, CatBoost
- Classification and regression algorithms

### C. Unsupervised Learning
- K-Means and hierarchical clustering
- DBSCAN and Gaussian Mixture Models
- PCA and dimensionality reduction
- Association rule learning
- Anomaly detection and market basket analysis

### D. Semi-supervised and Self-supervised Learning
- Pseudo-labelling, label propagation
- Self-supervised and contrastive learning
- Representation learning
- Foundation model pretraining

### E. Reinforcement Learning
- Agents, environments, states, actions, rewards
- Markov Decision Processes
- Q-Learning, Deep Q-Networks (DQN)
- Policy gradients, Actor-Critic methods, PPO
- Multi-agent reinforcement learning
- Practical reinforcement learning projects

### F. Deep Learning
- Artificial neural networks and perceptrons
- Feedforward networks, backpropagation
- Activation functions, loss functions, optimisers, gradient descent
- CNN, RNN, LSTM, GRU
- Autoencoders and GANs
- Transformers and attention mechanisms
- Transfer learning and fine-tuning

### G. Natural Language Processing (NLP)
- Text preprocessing, tokenisation, stemming, lemmatisation
- Text classification, sentiment analysis, NER
- Text summarisation and language modelling
- Word embeddings: Word2Vec, GloVe
- Transformers for NLP
- Machine translation, question answering, chatbot development
- Speech-to-text and text-to-speech

### H. Computer Vision
- Image processing, classification, object detection
- Image segmentation, face detection, facial recognition
- OCR, pose estimation, image generation
- Video analysis
- CNN architectures, YOLO, OpenCV, Vision Transformers
- Medical image analysis

### I. Time-Series Machine Learning
- Time-series analysis and forecasting
- Trend, seasonality, moving averages
- ARIMA, SARIMA, exponential smoothing, Prophet
- LSTM forecasting
- Demand forecasting, stock price modelling, predictive maintenance
- Anomaly detection in time-series data

### J. Recommender Systems
- Collaborative and content-based filtering
- Hybrid systems, matrix factorisation
- Similarity measures and personalisation
- Ranking algorithms and recommendation evaluation

### K. Probabilistic and Advanced ML
- Bayesian ML, Gaussian processes, probabilistic graphical models
- Hidden Markov Models
- Evolutionary and genetic algorithms
- Explainable AI (XAI), causal ML
- Federated learning, online learning, meta-learning
- Few-shot and continual learning

### L. MLOps and Production Machine Learning
- ML lifecycle, data versioning, experiment tracking
- Model versioning, deployment, serving and monitoring
- Model drift detection and retraining
- ML pipelines, feature stores, containerisation
- CI/CD for ML, cloud-based ML, model governance
- **Tools:** Scikit-learn, TensorFlow, PyTorch, Keras, XGBoost, Hugging Face, MLflow, DVC, Kubeflow, Weights & Biases
